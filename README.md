# Romaji

일본어 키보드를 설치하지 않고 로마자로 일본어를 입력할 수 있는 웹 도구입니다.

영어 알파벳으로 검색하면 히라가나, 가타카나, 한자 및 일본어 작품명 후보를 보여줍니다. 원하는 결과를 선택해 바로 복사할 수 있습니다.

## 주요 기능

- **로마자 변환** — 영어 알파벳으로 히라가나·가타카나 입력
- **한자 검색** — 일본어 사전을 기반으로 한자 후보 추천
- **작품명 검색** — 애니메이션·만화의 일본어 제목 검색
- **실시간 자동완성** — 입력 중 관련 후보 표시
- **사용자 사전** — 단어와 별칭 등록·수정·삭제
- **문장 작성** — 선택한 일본어를 원하는 위치에 삽입하고 편집
- **빠른 복사** — 검색 결과를 클릭해 즉시 복사
- **키보드 조작** — 방향키, Enter, Esc, 숫자키 지원
- **화면 설정** — 모바일 지원 및 라이트·다크 테마

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 검색창에 일본어 발음을 로마자로 입력합니다.
3. 표시된 후보 중 원하는 일본어를 선택합니다.
4. 복사한 일본어를 필요한 곳에 붙여 넣습니다.

별도의 회원가입, API 키, 프로그램 설치가 필요하지 않습니다.

## 입력 예시

| 입력 | 일본어 |
|---|---|
| `sakura` | さくら / サクラ / 桜 |
| `nihongo` | にほんご / 日本語 |
| `watashi` | わたし / 私 |
| `arigatou` | ありがとう / 有難う |

## 실행 환경

HTML 파일을 지원하는 최신 웹 브라우저에서 실행합니다.
